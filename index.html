Panduan & Setup Backend Node.js

Apa maksud fitur Backend ini & bagaimana cara pakainya?

Fitur ini menyediakan kode server mandiri (Node.js & Express) bagi Anda yang ingin menjalankan server database lokal atau cloud sendiri (misal di VPS, Heroku, atau komputer server sekolah).

  1. Salin kode skrip server.js di bawah ini.
  2. Buat folder baru di komputer, buat file bernama server.js lalu paste kodenya.
  3. Jalankan perintah npm init -y dilanjutkan npm install express cors di terminal.
  4. Nyalakan server dengan node server.js.
